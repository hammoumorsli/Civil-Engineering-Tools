# Outils Excel pour le Génie Civil

**Auteur : Morsli Hammou — Ingénieur en génie civil**

Bienvenue dans ce dépôt consacré aux outils de calcul Excel pour le génie civil.

## Contenu du dépôt

Ce dépôt propose des feuilles de calcul Excel destinées à faciliter les calculs techniques et les vérifications en ingénierie civile.

- **Calculs de structures**
- **Analyse sismique**
- **Béton armé et ferraillage**

Les outils disponibles seront présentés individuellement avec leur objectif, leurs données d'entrée et leurs résultats.

## Téléchargement

Les fichiers sont accessibles gratuitement. Ouvrez le fichier souhaité dans le dépôt et utilisez l'option de téléchargement.

## Avertissement

Les résultats doivent être vérifiés par un ingénieur qualifié avant toute utilisation dans un projet réel. Consultez les hypothèses et les références réglementaires applicables à chaque fichier.
